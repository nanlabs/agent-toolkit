# nanlabs-core

Baseline NaNLABS harness plugin for Claude Code / Cursor.

## Install

```text
/plugin marketplace add nanlabs/agent-toolkit
/plugin install nanlabs-core@nanlabs-agent-toolkit
```

Also install `nanlabs-setup` for first-run environment checks.

## Contents

Canonical copies of skills under `skills/` (Agent Skills layout) plus `agents/nanlabs-code-reviewer`.

Source of truth remains the repo-root `skills/core/` and `agents/` trees — keep plugin copies in sync when those change.
