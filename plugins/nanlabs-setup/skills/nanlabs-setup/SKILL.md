# NaNLABS Setup (deprecated)

**This standalone plugin is deprecated.** Setup (doctor, contracts, `/setup` command) now ships inside **`nanlabs-core`**.

## Migrate

```text
/plugin install nanlabs-core@nanlabs-agent-toolkit
```

Use **`/nanlabs-core:setup`**.

See [`DEPRECATION.md`](../../DEPRECATION.md) and [`docs/ADOPTION.md`](https://github.com/nanlabs/agent-toolkit/blob/main/docs/ADOPTION.md).
