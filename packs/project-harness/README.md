# Project Harness

Provisional solution pack stub for **composing** platform capabilities required
by a specific engagement (plan §4.5).

This is the public example used by overlay governance — not a client pack.

## Use cases

- Declare which core plugins a project needs
- Point humans at overlay checklist without copying central skills
- Keep credentials in L1

## Example metadata

See `overlay.yaml` in this directory.

## Composes (intent)

- `nanlabs-setup`, `nanlabs-core`, `nanlabs-agents`
- Optional: engineering-workflow + delivery-discipline packs
- MCP stubs as needed (`mcp/templates/`) via L1 env
