# User Story (WHAT)

Use for user-centered requirements that need business value, technical notes, and acceptance criteria.

## Default guardrails

1. Apply **`nanlabs-output-handshake`** before final output.
2. Use **`nanlabs-planning`** when estimation or splitting is needed.
3. Use **`nanlabs-task`** for purely technical work that is not a user story.
