# agent-toolkit

NaNLABS skills, agents, plugins, MCP integrations, and reusable workflows for AI agents across Claude Code, Cursor, Copilot, OpenCode, and other compatible clients.

> **Status:** Repository created. Content migration from [`internal-workstation`](https://github.com/nanlabs/internal-workstation) is tracked in GitHub Project [AI Native Workbench](https://github.com/orgs/nanlabs/projects/12).
>
> **Canonical plan:** [`docs/AI_ASSETS_MIGRATION_PLAN.md`](https://github.com/nanlabs/internal-workstation/blob/main/docs/AI_ASSETS_MIGRATION_PLAN.md) in `internal-workstation`.

## Install (target UX — after P0)

```bash
# Claude Code
/plugin marketplace add nanlabs/agent-toolkit
/plugin install nanlabs-setup

# Any agent (technical)
npx skills add nanlabs/agent-toolkit -g
```
