# 🤖 Agents reference

18 personas under `agents/<name>/AGENT.md`. Plugin surfaces are **flat** `plugins/*/agents/<name>.md` generated by `scripts/gen-surfaces.py`.

Catalog: [`catalogs/agent-catalog.yaml`](https://github.com/nanlabs/agent-toolkit/blob/main/catalogs/agent-catalog.yaml) · audit: [`docs/AGENT_AUDIT.md`](https://github.com/nanlabs/agent-toolkit/blob/main/docs/AGENT_AUDIT.md).

## Roster

| Agent | Typical use |
| --- | --- |
| `nanlabs-code-reviewer` | Quality / security / maintainability review (also in **core**) |
| `nanlabs-architect` | System design / tradeoffs |
| `nanlabs-planner` | Implementation planning |
| `nanlabs-security-reviewer` | Vulnerability-focused review |
| `nanlabs-database-reviewer` | PostgreSQL / schema / ORM |
| `nanlabs-typescript-reviewer` | TypeScript safety |
| `nanlabs-tdd-guide` | Tests-first guidance |
| `nanlabs-e2e-runner` | Playwright E2E |
| `nanlabs-build-error-resolver` | Build / type / CI failures |
| `nanlabs-performance-optimizer` | Perf / memory |
| `nanlabs-refactor-cleaner` | Dead code / simplification |
| `nanlabs-docs-lookup` | Framework / API docs |
| `nanlabs-reference-lookup` | Ecosystem reference patterns |
| `nanlabs-assistant` | Repo discovery / orchestration |
| `nanlabs-client-workflow-bootstrap` | Client workflow skill pairs |
| `nanlabs-devcompanion-lead` | Dev-companion queue / plan lead |
| `nanlabs-forge-pr` | Draft PR / MR from current branch |
| `nanlabs-data-validator` | Data / ETL contract checks |

## Install

- **Core plugin:** includes `nanlabs-code-reviewer` only.
- **Agents plugin:** `/plugin install nanlabs-agents@nanlabs-agent-toolkit` (or Cursor equivalent) for the full set.
