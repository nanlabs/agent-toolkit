# Figma MCP

Official remote MCP (Streamable HTTP + OAuth). No personal access tokens.

- Endpoint: `https://mcp.figma.com/mcp`
- Docs: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/
- Plugin: `nanlabs-design` (`mcp.json`)

Figma allowlists MCP clients (Cursor, VS Code, Claude Code, and others in their
catalog). Authenticate in the client after plugin install.
