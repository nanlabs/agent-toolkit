# GitLab MCP

Official GitLab.com MCP (Streamable HTTP + OAuth / DCR).

- Endpoint: `https://gitlab.com/api/v4/mcp`
- Docs: https://docs.gitlab.com/user/model_context_protocol/mcp_server/
- Plugin: `nanlabs-forge` (`mcp.json`)

Self-managed instances use `https://<host>/api/v4/mcp` in **user** MCP config,
not this plugin (the plugin targets GitLab.com).
